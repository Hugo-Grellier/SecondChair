# Triage labels

| Role | GitHub label |
| --- | --- |
| Ready for an agent | `ready-for-agent` |
| Requires a human | `ready-for-human` |

Use these exact labels when a skill refers to a triage role. The repository has no `needs-triage`, `needs-info` or `wontfix` label: an untriaged issue simply has neither label, a blocking question is a comment plus `ready-for-human`, and a declined issue is closed as not planned. Priority stays in the title prefix (`[HIGH][P1]`, `[P2]`). The `wayfinder:*` labels belong to the planning workflow and carry no triage role.
