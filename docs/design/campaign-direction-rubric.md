# Judging a campaign-direction pitch set

Status: guidance for the GM and reviewers of the `develop-campaign-direction` skill ([#175](https://github.com/Hugo-Grellier/SecondChair/issues/175)). It binds nothing. Scores are human and reported only, never a bench metric ([editorial-evaluation.md](editorial-evaluation.md), MET-03).

The skill's own critique checklist (clichés, false choices, PC relevance, pacing, accidental railroading, payoff without setup, unearned revelations) is written into each pitch and is flags only. This page judges the **set** as a whole.

## How a set is judged

Score each dimension 1 to 5 with one sentence citing the passage, as in the editorial rubric.

| Dimension | 1 | 3 | 5 |
|---|---|---|---|
| **Distinctness** | Three costumes of one plot: same conflict, same antagonist pressure | Different villains or settings over the same structure | Different central conflict, structure or pressure; choosing one closes real doors |
| **Canon citations** | No canon ids, or ids that do not resolve (`secondchair notes check` reports them) | Entities named, few facts cited | Each pitch cites the facts, factions and open situations it builds on, and says what it would change |
| **Open-endedness** | A fixed ending or a mandatory sequence | Open questions, but one route to the revelations | Arcs are pressures and questions; each revelation has causes and several player paths; ignoring a hook has a defined world reaction |
| **Table fit** | Ignores the brief's lines, veils or promise | Respects them; PC hooks generic | Every PC has a stake tied to what their player said; near-term beats are playable next session |

## Comparison with a single-prompt generation

For the same brief and canon, generate one pitch with a single prompt ("write a campaign for this"). Judge it and the skill's set blind, with the same table. Expect the set to win on **distinctness** (a single prompt yields one architecture), on **canon citations** (the skill reads canon first and lists the ids it respects) and on **open-endedness** (the skill forbids a fixed ending). The single prompt may win on speed and polish of one pitch. If the set does not beat the single prompt on at least distinctness, the skill has failed this test and its pitch instructions need work.
